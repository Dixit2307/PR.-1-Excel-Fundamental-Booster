## ✨ About the Project

**Excel Fundamental Booster** is a practical spreadsheet project designed to strengthen core and intermediate Microsoft Excel skills through realistic datasets.

The workbook contains student grades, sales records, and employee information. It provides practice in applying formulas, automating calculations, retrieving information, formatting data, and extracting meaningful results.

> **Goal:** Build confidence in using Excel formulas to solve everyday data-management and analysis tasks.

## 📁 Workbook Structure

| Worksheet | What it contains |
|---|---|
| `Project Instructions` | Topics, task descriptions, and project requirements |
| `Students Grade` | Student marks, totals, percentages, grades, and subject conditions |
| `Sales Data` | Product sales, discount calculations, and final amounts |
| `Employee Data` | Employee details, salary, joining dates, and text/date calculations |

## 🧠 Excel Skills Practiced

### 1. Cell References & Formatting
- Relative and absolute cell references
- Data input and worksheet formatting
- Number, currency, and date formatting

### 2. Logical Functions
- `IF` and nested `IF`
- `AND` and `OR`
- Conditional classification and discount calculations

### 3. Conditional Analysis
- `COUNTIFS`
- `SUMIFS`
- `AVERAGEIFS`

### 4. Lookup & Search Functions
- `VLOOKUP`
- `XLOOKUP`
- `XMATCH`
- `INDEX` + `MATCH`

### 5. Text Functions
- `LEFT`
- `SEARCH`
- `UPPER`
- `LOWER`

### 6. Dynamic References & Data Extraction
- `INDIRECT`
- `OFFSET`
- `FILTER`

### 7. Date, Time & Math Functions
- `DATEDIF`
- `TODAY`
- `SUM`
- `AVERAGE`
- `ROUND`
- Date and tenure calculations

## 🎯 Key Project Tasks

- Classify students based on their percentage using nested `IF` formulas.
- Count students who score above a specified mark using `COUNTIFS`.
- Retrieve product prices from sales data using lookup formulas.
- Fetch employee salary information dynamically using `XLOOKUP`.
- Calculate employee service duration from joining dates.
- Extract students scoring above 80 using the `FILTER` function.
- Calculate sales discounts and final payable amounts using logical formulas.

## 🚀 How to Use

1. Download or clone this repository.
2. Open the Excel workbook (`.xlsx`) in Microsoft Excel.
3. Start with the **Project Instructions** worksheet.

5. Review the formulas and experiment with different values.
